# Spicetify AutoUpdater

## Instalación

1. Abre la página **Releases** de este repositorio y descarga `SpicetifyAutoUpdater.exe`.
2. Ejecuta el archivo descargado. Se instalará en tu usuario de Windows y se iniciará con Windows.
3. En la ventana que se abre, haz clic en **Install / Update** para instalar Spicetify, Marketplace y la extensión.

Se necesita conexión a Internet para completar la instalación.
